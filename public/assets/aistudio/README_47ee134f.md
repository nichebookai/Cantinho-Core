# Sorveteria Core — Modelo Limpo para Novo Negócio

Esta pasta `/modelo_limpo_sorveteria` contém a estrutura limpa e genérica do sistema de gestão financeira, de estoque e de vendas adaptado para uma **Sorveteria, Açaí & Gelateria**.

---

## 📁 O que está incluído nesta pasta:

1. **`PROMPT_TECNICO_RECIACAO.md`**: Prompt pronto para colar no Google AI Studio para recriar o projeto do zero em uma nova applet.
2. **`src/types/index.ts`**: Tipos TypeScript configurados para sorvetes, picolés, açaí, toppings e embalagens.
3. **`src/data/initialData.ts`**: Dados iniciais genéricos de sorveteria para você preencher com os seus custos e preços reais.
4. **`src/context/BusinessContext.tsx`**: Mecanismo de estado offline-first com sincronização cardápio-estoque e controle de caixa auditável.
5. **`src/utils/deterministicMath.ts`**: Fórmulas matemáticas determinísticas para CMV, Lucro Bruto, Margem % e Fluxo de Caixa.
6. **`src/pages/` & `src/components/`**: Módulos visuais prontos.

---

## 🚀 Como usar para criar seu novo projeto:

1. Baixe esta pasta `/modelo_limpo_sorveteria` para o seu computador.
2. Abra um novo applet no **Google AI Studio Build**.
3. Envie os arquivos desta pasta ou copie o conteúdo do arquivo `PROMPT_TECNICO_RECIACAO.md` e cole na conversa inicial.
4. O AI Studio criará a sua sorveteria limpa, pronta para você cadastrar seus sabores, picolés e preços reais!

---

*Nota: Após baixar esta pasta, você pode excluí-la do seu projeto Xamã na Brasa se desejar.*
